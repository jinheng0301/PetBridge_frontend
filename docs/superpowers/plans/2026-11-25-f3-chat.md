# F3 聊天：成员私聊与小屋通知 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 同屋成员各写母语、各看母语：一对一私聊 + 全屋公告板“小屋通知”，由发送者的宠物以信使卡片送达；断线、失败、撤回都不漏不重。

**Architecture:** 后端只加筛选参数与通知上限，并修 `delivery` 可空契约。前端用每用户一个 drift 库作唯一展示来源：`ChatSync`（WS 事件 + REST 补消息）与 `ChatSender`（outbox）只写库，页面只订阅库。`RealtimeCoordinator` 只多一条信号流。分 F3a（Task 1–11）与 F3b（Task 12–16）。

**Tech Stack:** Flutter 3.50.0 / Dart 3.14.0、flutter_riverpod 3、go_router、dio + retrofit（swagger_parser）、gen-l10n、mocktail、fake_async；新增 `drift`、`drift_flutter`，dev 新增 `drift_dev`。后端 Go / gin / pgx。

**Spec:** `docs/superpowers/specs/2026-11-25-f3-chat-design.md`（另见后端 TRD 7.4、7.9、第 9 章）

## Global Constraints

- **开工前置**：F2 双机验收（F2 计划 Task 8、12）通过。B6b 已提交推送（后端 `ad3e78f`、前端 `46880b4`）。
- 私聊与小屋通知绝不混在同一列表；`scope=room` → 小屋通知，`scope=dm` → 与“不是我的那一方”的私聊。
- 文本去首尾空白后 1–500 字，按 Unicode 字符计（Dart `runes`）；发送只靠按钮，回车换行。
- `client_msg_id`：128 位 `Random.secure` 的 32 位小写十六进制；重试永远沿用原值。
- 小屋通知每人每间小屋每天 10 条（发送者时区），429 `RATE_LIMITED` + `details.reason = "notice_daily"` + `Retry-After`。
- 未成年人（`ageBand != '18_plus'`）没有私聊入口，进私聊路由退回 `/home/chat`。
- 状态只前进：`translation` `pending < failed < done`；`polish` `none < pending < done / fallback`；两者分别判断。
- 翻译失败**没有**重试按钮；`CONTENT_BLOCKED` 不可重试、不说明原因。
- 补消息：混合接口、`limit=100`，起点往前 10 秒，且不晚于 24 小时内最早未定消息前 1 毫秒；连接断开或 `resync` 后游标冻结到补完为止。
- 本地消息保留 30 天；离开小屋删该房间全部聊天数据；登出删整个库；会话过期不删。
- 不引入 `connectivity_plus`，不加 REST 层自动重试拦截器。
- 生成代码只在 `data/` 用；UI 只认 `error.code`（与 `details.reason`）。沿用仓库的 `const new(...)` 写法与 `roomViewProvider` 等既有 provider。
- 五语 ARB：`en`、`zh`、`zh_Hans` 由实现者按下表写（`zh` 与 `zh_Hans` 都是简体），`ja`、`ko`、`zh_Hant` AI 初译并保持 `@@x-reviewed: false`；简繁不混字。
- 点按区域 ≥ 48；卡片、按钮有 Semantics。
- 每个任务结束 `flutter analyze` 与 `flutter test` 全绿；后端任务结束 `go vet ./...` 与 `go test -p 1 ./...` 全绿。
- **提交**：先给用户审 diff，通过后才提交；按任务（必要时按阶段）拆成多个提交；前后端都推送 `jinheng main`；只提交本任务的文件。

## Review Focus

1. **补消息翻页途中来了实时消息**：中间那段不能丢 → Task 6 `live message during catch-up does not skip the gap`。
2. **POST 超时但服务端已存**，`message.new` 先于重试到达：只剩一个气泡 → Task 7 `echo of a timed-out send removes the pending bubble`。
3. **登出或换账号时补消息 / 发送还在飞**：结果不写进别人的库、已关闭的库不抛错 → Task 6 `late page after dispose is dropped`。
4. **被移出后又重新加入同一间小屋**：旧历史与旧游标已清，重新首次同步 → Task 6 `rejoined room syncs from scratch`。
5. **emoji 与日文输入法**：500 个 emoji 可发、501 个不可；输入法组字中回车不发送 → Task 10 `counts runes and never sends on enter`。
